❧ Que es MEMORY TECHNOLOGY

▸ Una microempresa llamada “Memory Technology” que se dedica a la venta de un programa de software para personas con problemas de memoria internacional. Su única sede se encuentra en la ciudad de Bogotá, desde la cual se coordina toda su información, todos sus programas, todas sus actualizaciones, el inventario y se organiza toda la información que se tiene de cada uno de los programas. Las principales problemáticas vistas en esta empresa fueron la gran cantidad de volumen de datos, la limitación para las tareas múltiples, y la comprensión de sus conclusiones, se quiere diseñar un software en el cual se puedan solucionar toda estas problemáticas, este software tendrá gran manejo en el volumen de datos, les proporcionará una mejor comprensión de las conclusiones, y su limitación de tareas múltiples será expandida, logrando así que este logre una mayor cantidad de tareas y la organización de la base de datos.

❧ Nuestro objetivo

▸ Es desarrollar un sistema informático para ayudar a las personas con problemas de memoria como lo podemos lograr, Aplicando los distintos métodos de información para conocer todos los requerimientos de las personas con problemas de memoria, Diseñar posiblemente todos los modelos de entidad relación que nos van a ayudar con la solución de la aplicación, Hacer la creación del sistema de información que requiere el memory tecnology en capas que requiere Oracle ápex y visual estudio, Diseñar los diferentes modeles UML tales como diagrama de clases, modelo entidad relación (MER) y casos de uso para memory tecnology, Desarrollar un sistema de información y Realizar las pruebas del sistema de información para comprobar su validez. Así haremos todo lo posible para que esto salga a flote.

❧ Mision

▸ Con nuestra aplicación ayudar a personas con problemas de memoria para que puedan empezar a recordar mediante diferentes opciones (imágenes, videos, recordatorios, etc.) cosas importantes como sus familiares.

❧ Vision

▸ Ser reconocidos como una empresa local que apoya a las personas con problemas de memoria para poder mejorar la vida cotidiana del ciudadano y así lograr expandir la empresa internacionalmente.
